# CODE — Scientific Programming and High Performance Computing

This repository contains teaching materials and practical assignments for the **Scientific Programming and High Performance Computing (CODE)** course, part of the [Master's Degree in Computational and Data-Assisted Engineering (CODE)](https://camins.upc.edu/en/Studies/master/code) at the Universitat Politècnica de Catalunya (UPC).

## Contents

- [`course-project/`](course-project/): Course project and associated implementation tasks.
- [`exercises/`](exercises/): Programming exercises and practical activities.
- [`lecture-materials/`](lecture-materials/): Supporting materials for lectures.
- [`tutorials/`](tutorials/): Tutorials and supplementary learning resources.

Directories will be populated as the course materials are developed.

## Requirements

The course uses Python and its scientific computing ecosystem. Specific dependencies and installation instructions are provided alongside the relevant activities.
